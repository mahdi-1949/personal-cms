Syntax check برای ۴۶ فایل JavaScript بدون خطا انجام شد. ساخت حساب مدیر با CLI و ورودی رمز پنهان در نسخه اولیه امتحان شد؛ دیتابیس‌ها و رسانه آزمایشی وارد مخزن نمی‌شوند.

کنترل تعارض ویرایش و حذف، escaping متن عمومی، عدم ورود اطلاعات خصوصی به خروجی ثابت و عدم پاک‌کردن پوشه‌های غیرمرتبط نیز در تست‌ها بررسی شدند.

این گزارش شامل بررسی محلی و بازیابی داده آزمایشی است. نتیجه CI گیت‌هاب از بخش Actions مخزن قابل مشاهده خواهد بود. تست کامل همه مرورگرها، آزمون بار، حسابرسی امنیتی مستقل و استقرار production در این مرحله انجام نشده‌اند.

## آزمون‌های امنیت اضافه‌شده

- TOTP با بردارهای RFC 6238، رمزگذاری وابسته به context و رد مصرف دوباره کد.
- MFA، CSRF/رمز فعلی، کد بازیابی یک‌بارمصرف و ابطال نشست‌ها.
- سیاست اجباری مدیر، حفاظت عامل دوم در reset و تغییر رمز از مسیر HTTP با TOTP.
- پاسخ یکسان reset، صف رمزگذاری‌شده، انقضا/یک‌بارمصرف و ابطال با تغییر حساب.
- عدم افشای راز/رمز/توکن در گزارش و منع دسترسی editor.
- ورود با هش قدیمی و ارتقای آن، و زنجیره IP پراکسی بدون اعتماد به header جعلی.
- بکاپ با حفظ MFA فعال و حذف reset/صف/pending، و رد کلید ناسازگار پس از restore.
- رد تصویر با header معتبر و پیکسل خراب، حذف EXIF/ICC، اعمال چرخش و decode خروجی.
- سقف پیکسل/حجم، resize و ارتقای تصویر قدیمی با قفل نصب.

`npm audit --omit=dev --audit-level=high` پس از ارتقای Sharp به 0.35.5، صفر آسیب‌پذیری شناخته‌شده گزارش کرد. این نتیجه حسابرسی مستقل نیست. SMTP در تست‌ها mock شده و تحویل واقعی هنوز بررسی نشده است. دانلود مستقیم Chromium ابتدا ناموفق بود؛ در ادامه برای نسخه 0.5 مرورگر از بسته npm موقت آماده شد و آزمون جریان‌های اصلی روی Chromium 153.0.8010.0 انجام شد. این بسته موقت وارد وابستگی‌های CMS نشده است.

## قالب و آزمون مرورگر نسخه 0.5

هفت تست اضافه‌شده انتخاب امن قالب/رنگ و تعارض، حفظ متن/بلوک هنگام تغییر طرح، پیش‌نمایش خصوصی، تصاویر/مقصدهای تو‌در‌تو، اعتبارسنجی بخش‌ها، export با زیرمسیر و ارتقای schema 4/بکاپ را بررسی می‌کنند.

`npm run test:browser` با داده موقت و mock SMTP موفق شد: ورود، تغییر قالب/رنگ، آپلود، ساخت و جابه‌جایی بخش‌ها و کارت‌ها، preview پیش‌نویس، تغییر طرح و انتشار، پرسش بازشونده، فعال‌سازی MFA و ورود با کد بازیابی و reset رمز از صفحه اختصاصی. در جریان‌های آزموده‌شده خطای JavaScript یا نقض CSP مشاهده نشد.

نمای عمومی در عرض‌های ۱۴۴۰ و ۳۹۰ و ویرایشگر در موبایل بررسی شد؛ تصویر کامل بارگیری شد و overflow افقی صفحه عمومی/ویرایشگر وجود نداشت. screenshotهای دسکتاپ preview و صفحه خدمات/ویرایشگر موبایل نیز بصری بازبینی شدند. این بررسی محدود به محتوای آزمایشی و Chromium است؛ تمام مرورگرها، صفحه‌خوان، بار و محتوای واقعی مشتری هنوز بررسی نشده‌اند.

CI نصب Playwright Chromium و همین آزمون مرورگر را پس از تست API اجرا می‌کند. بدون مرورگر نصب‌شده، تست محلی مرورگر نیازمند `npx playwright install --with-deps chromium` یا مسیر اجرایی معتبر در `CMS_TEST_BROWSER_EXECUTABLE` است.
