# بررسی نسخه 0.7.0

تاریخ بررسی محلی: ۱۰ اکتبر ۲۰۲۶. این گزارش مربوط به داده آزمایشی است؛ نصب روی هاست واقعی، تحویل SMTP واقعی و حسابرسی مستقل امنیتی هنوز انجام نشده‌اند.

## بررسی خودکار

- `npm run check`: ۵۸ فایل JavaScript بدون خطای نحوی.
- `npm test`: ۷۵ تست موفق، بدون شکست/حذف/skip.
- `npm audit --omit=dev --audit-level=high`: صفر آسیب‌پذیری شناخته‌شده گزارش شد؛ این نتیجه حسابرسی مستقل نیست.
- `npm run test:browser`: جریان‌های زیر روی Chromium 153.0.8010.0 با داده موقت و mock SMTP موفق شدند. مرورگر از بسته npm موقت خارج از وابستگی‌های CMS آماده شد؛ آماده‌سازی Chromium محلی خارج از وابستگی‌های پروژه انجام شد. CI مرورگر استاندارد Playwright را نصب می‌کند.

## مرورگر و بازبینی بصری

ورود، قالب/رنگ، آپلود، بخش‌ها/کارت‌ها، جابه‌جایی، preview خصوصی، انتشار، موبایل، MFA و reset رمز از نسخه قبل دوباره بررسی شدند.

در فضای طراح، ساخت نمونه، tab کد، autosave، بازیابی تاریخچه، انتشار رمز، preset کامل/بخش، undo، کشیدن فهرست ترتیب و پیش‌نمایش موبایل/دسکتاپ صفحه ذخیره‌شده آزمایش شدند. Three.js روی WebGL نرم‌افزاریِ مرورگر headless واقعاً مثلث رندر کرد و context از دست نرفت؛ صحنه زنده و export با زیرمسیر و هدرهای لازم رندر شدند. کاهش حرکت، دکمه توقف و fallback با غیرفعال‌کردن WebGL در context آزمایشی بررسی شدند. آزمون بار یا عملکرد GPU موبایل واقعی محسوب نمی‌شود.

کد آزمایشی برای خواندن DOM والد، کوکی، localStorage و fetch API مدیریت مسدود شد. متن حاوی markup در کنسول به HTML تبدیل نشد. نقض CSP فقط برای fetch عمدیِ مسدودشده انتظار رفت؛ دیگر جریان‌های موفق خطای JavaScript یا CSP نداشتند. URL مستقیم runtime ثابت نیز با HTTP sandbox، دسترسی کوکی را مسدود کرد. میزبان ثابت آزمایش، هدرهای CORS/CSP لازم را اعمال کرد؛ این تنظیم خودکار همه میزبان‌ها یا GitHub Pages نیست.

صفحه خدمات و صفحه اصلی سه‌بعدی در عرض ۱۴۴۰/۳۹۰، ویرایشگر محتوا روی موبایل و فضای طراح با قاب موبایل بررسی شدند. تصاویر بارگیری و overflow افقی صفحه عمومی/ویرایشگر رد شد. screenshotهای سیستم طراحی، فضای کد/سه‌بعدی، صفحه اصلی موبایل/دسکتاپ و خدمات بصری بازبینی شدند. قاب preview ارتفاع مشخص و اسکرول داخلی دارد؛ این بررسی جای تست محتوا/اندازه قاب سایت واقعی را نمی‌گیرد.

## بررسی پیش از عرضه

CI از Actions مخزن قابل مشاهده است و همین syntax/API/audit/browser را اجرا می‌کند. Firefox، Safari، صفحه‌خوان، تست بار، ارزیابی مستقل امنیت، SMTP واقعی، سنجش صحنه روی موبایل واقعی، staging و بازیابی روی هاست هنوز باقی‌اند. مدل GLB و loaderهای تأییدشده اضافه شده‌اند؛ WOFF2/فونت سراسری قالب، مدل فشرده، React/TSX و تاریخچه/autosave صفحات محتوا همچنان باقی‌اند.

## دارایی‌های طراحی در 0.7

شش تست تازه شامل GLB/WOFF معتبر، رد header/chunk/URI/data URI/extension فشرده/accessor نامعتبر، تصویر خراب، تعداد node/عمق نامجاز، checksum/offset/inflate نامعتبر فونت، سقف حجم و مجوز طراح هستند. منابع خارجی توسط validator بارگیری نمی‌شوند. scope و انقضای توکن، حذف نشست، عمومی‌شدن فقط با release ارجاع‌شده، منع حذف تاریخی و رد استفاده از مدل/فونت در بلوک تصویر بررسی شدند. بکاپ/بازیابی فایل‌های GLB/WOFF را عیناً حفظ می‌کند و normalize-media آن‌ها را نادیده می‌گیرد؛ خروجی فقط دارایی نسخه عمومی و loaderهای فهرست تأییدشده را همراه زیرمسیر صادر می‌کند.

آزمون Chromium بارگذاری از پنل، انتخاب مدل، درج کد FontFace، decode فونت واقعی و رندر GLB با بافت داخلی را در preview خصوصی، سایت عمومی و export مستقل بررسی می‌کند. مدل آزمایشی keyframe rotation نیز دارد. این نتیجه درباره فایل آزمایشی است؛ پشتیبانی همه مدل‌های بازار، همه فونت‌ها، شبیه‌سازی عملکرد GPU موبایل یا امنیت قطعی decoder نیست. تصاویر پنل مدل/فونت و صفحه عمومی/خروجی موبایل بازبینی می‌شوند. مرورگر CI از Playwright نصب می‌شود.
