# بررسی نسخه 0.1.0

تاریخ بررسی: ۹ اکتبر ۲۰۲۶.

`npm test`: ۸ تست، ۸ موفق، بدون تست ردشده.

| بررسی | نتیجه |
| --- | --- |
| هش رمز و نشست، کوکی و کنترل Origin/CSRF | موفق |
| خصوصی‌ماندن پیش‌نویس، انتشار HTML و canonical/sitemap | موفق |
| برخورد slug، جلوگیری از traversal و نگهداری امن متن در SQL | موفق |
| اجازه ایجاد محتوا برای editor و منع تنظیمات/حذف | موفق |
| غیرفعال‌کردن ماژول بدون پاک‌شدن داده | موفق |
| خروجی Pages با زیرمسیر، حذف صفحات قدیمی و حفاظت مسیر خروجی | موفق |
| ماندگاری داده پس از اتصال مجدد و خروج از نشست | موفق |
| محدودیت تلاش ورود ناموفق | موفق |

Syntax check برای ۱۱ فایل JavaScript بدون خطا انجام شد. ساخت حساب مدیر با CLI و ورودی رمز پنهان در ترمینال امتحان شد؛ دیتابیس آزمایشی وارد بسته تحویلی نشده است.

کنترل تعارض ویرایش و حذف، escaping متن عمومی، عدم ورود اطلاعات خصوصی به خروجی ثابت و عدم پاک‌کردن پوشه‌های غیرمرتبط نیز در تست‌ها بررسی شدند.

این گزارش نتیجه بررسی محلی است. نتیجه CI گیت‌هاب از بخش Actions مخزن قابل مشاهده خواهد بود. تست کامل مرورگر، آزمون بار، حسابرسی امنیتی مستقل و استقرار production در این مرحله انجام نشده‌اند.
